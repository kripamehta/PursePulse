# PursePulse 💰

PursePulse is a responsive personal finance dashboard designed to help users track their income, expenses, budgets, financial goals, and spending patterns in one place.

## 🚀 Features

- Dashboard with financial summary
- Income and expense tracking
- Add and manage transactions
- Transaction filtering
- Category-based spending analysis
- Financial goal tracking
- Quick transfer interface
- Accounts overview
- Bills and subscriptions section
- Light/Dark theme switching
- Persistent data using LocalStorage
- Responsive user interface
- Interactive charts and financial insights

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript
- LocalStorage
- Lucide Icons
